# RiskOps AI

Portfolio-grade, human-in-the-loop insider-risk analytics on the **synthetic** CMU SEI CERT Insider Threat Test Dataset. It is a research MVP—not a production surveillance, employment, or access-control system.

> No raw CERT files, answer keys, derived score data, models, secrets, or credentials are committed here.

## What it demonstrates

- Chunked Pandas event aggregation and DuckDB Parquet output
- Leakage-aware, chronological Isolation Forest baseline
- Held-out precision, recall, F1, and PR-AUC (when both classes exist)
- Streamlit/Plotly analyst dashboard with evidence-grounded report drafts
- n8n review-queue example that explicitly performs no automated action
- Tests that guard label leakage and answer-key window expansion

## Data provenance, version, and terms

The source is the [official CMU SEI CERT dataset page](https://www.sei.cmu.edu/library/insider-threat-test-dataset/) and its [DOI archive](https://doi.org/10.1184/R1/12841247.v1). SEI describes the collection as synthetic background and malicious-actor data, generated by CERT with ExactData under DARPA I2O sponsorship. This project selects official release **r4.2**. The archive metadata lists **CC BY 4.0**; dataset-specific README files inside each release are the source for release conventions. Do not use an unclear Kaggle mirror as a redistribution source.

The separate official answer archive (`answers.tar.bz2`) includes scenario and synthetic-user details. Its `insiders.csv` file supplies the ground-truth windows used solely for offline benchmark evaluation. Full handling instructions and schema contract: [data/README.md](data/README.md).

## Quick start on Windows

```powershell
git clone https://github.com/Deepakns021/riskops-ai.git
cd riskops-ai
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
$env:PYTHONPATH = "src"
pytest -q
```

1. Download `r4.2.tar.bz2` and `answers.tar.bz2` directly from the official DOI archive.
2. Validate the official checksums; extract the required files into the ignored paths documented in [data/README.md](data/README.md).
3. Build the local artifact: `python -m riskops.pipeline`
4. Start the dashboard: `streamlit run app/streamlit_app.py`

The first pipeline execution is deliberately local and may take time: the original event archives are multi-gigabyte. Results are only meaningful for this synthetic benchmark and must be rerun locally before being reported.

## Design safeguards

- The answer key is not a feature and is never available to the model.
- Time is split chronologically: fitting occurs before evaluation.
- The UI labels scores as review candidates, not findings.
- Reports contain only displayed evidence and require human disposition.
- The n8n sample queues review only; it cannot discipline people, revoke access, or create other automated consequences.

See [architecture](docs/ARCHITECTURE.md) and [n8n operating notes](docs/OPERATIONS.md).
